## PC Migrate Portable 1.2.0 — 4 languages / 4 langues / 4 لغات / 4 idiomas

### ⬇️ Download
| File | Use |
|---|---|
| **PCMigrate-Setup.exe** | Installer — the installer language becomes the app language |
| **PCMigrate-Portable.zip** | USB stick / Hiren's BootCD PE (`Run-PCMigrate.bat`, `Copy-To-USB.bat`) |
| **PCMigrate.exe** | The program alone, fully portable |

### New in 1.2
- 🌍 **Interface in English, Français, العربية (right-to-left) and Español** — detected from Windows automatically
- ⚙️ **Settings** window: change the language any time after installation (saved in `PCMigrate.ini`, or `--lang=fr|en|ar|es`)
- The installer is available in the same 4 languages and passes its language to the app
- Stable download names: `PCMigrate-Setup.exe` / `PCMigrate-Portable.zip` (links always point to the latest version)

### Nouveautés · الجديد · Novedades
- 🇫🇷 Interface en français, arabe, anglais et espagnol ; changement de langue dans **Paramètres**.
- 🌍 واجهة بالعربية (من اليمين إلى اليسار) والفرنسية والإنجليزية والإسبانية، مع تغيير اللغة من **الإعدادات**.
- 🇪🇸 Interfaz en español, francés, árabe e inglés; cambio de idioma en **Ajustes**.

> ⚠️ Not digitally signed — SmartScreen: **More info → Run anyway**. Program transfer is experimental: try it in a VM first.
