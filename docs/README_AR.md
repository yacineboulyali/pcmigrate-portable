# PC Migrate Portable 1.1

برنامج لنقل المستخدم من حاسوب قديم إلى حاسوب جديد، على طريقة PCmover.

- **Portable 100%:** ملف واحد `PCMigrate.exe` حجمه حوالي 470 KB.
- **مكتوب بـ C++ / Win32 API ومربوط ربطًا ثابتًا (Static):** لا يحتاج .NET ولا Python ولا أي مكتبة. يعتمد فقط على ملفات DLL الموجودة في كل ويندوز وفي WinPE.
- **أين يعمل؟** على Windows 10/11 العادي، وداخل **Hiren's BootCD PE** عند الإقلاع من USB.

---

## ماذا ينقل؟

| العنصر | التفاصيل |
|---|---|
| ملفات المستخدم | Desktop، Documents، Downloads، Pictures، Music، Videos، Favorites، Links، Contacts، Saved Games. ينقل أيضًا مجلدات OneDrive المحوَّلة (Desktop، Documents، Pictures) |
| المتصفحات | Chrome، Edge، Brave، Opera، Opera GX، Firefox: المفضلة والسجل والإضافات والإعدادات (بدون الكاش) |
| إعدادات ويندوز | الماوس، لوحة المفاتيح ولغات الإدخال، الإعدادات الإقليمية، الألوان والوضع الداكن، خيارات Explorer، المؤشرات، Console، خلفية سطح المكتب، تثبيتات Quick Access |
| Wi-Fi | شبكات Wi-Fi المحفوظة |
| **نقل البرامج مع بياناتها** (جديد) | البرامج التي تختارها تُنقل كاملة: ملفات البرنامج، مفاتيح الـ Registry، الخدمات (Services)، اختصارات قائمة ابدأ، وبيانات كل مستخدم (AppData و ProgramData و HKCU) |
| إعادة التثبيت عبر winget | قائمة كل البرامج المثبتة، وإعادة تثبيتها نظيفةً عبر **winget** (أكثر من 70 برنامجًا معروفًا مُعرَّف مسبقًا، والبقية يُبحث عنها بالاسم) |

## طريقة الاستعمال

### 1) على الحاسوب القديم: Backup
- **الطريقة الأولى، من Hiren's BootCD PE (يُنصح بها):** أقلع من الفلاشة وشغّل `PCMigrate.exe`. الملفات تكون غير مقفلة، وتستطيع قراءة ملفات كل المستخدمين حتى بدون كلمات مرورهم.
- **الطريقة الثانية، من ويندوز العادي:** شغّل البرنامج كمسؤول، وهو يطلب ذلك تلقائيًا. **أغلق المتصفحات قبل البدء.**

ثم:
1. اختر قرص ويندوز القديم من القائمة (يُكتشف تلقائيًا).
2. حدّد المستخدمين وما تريد نقله.
3. **لنقل البرامج:** فعّل **Programs with their files & data** ثم اضغط **Choose...**. تظهر قائمة البرامج مع حجمها ومكان تثبيتها، فحدّد ما تريد نقله.
4. اختر قرصًا خارجيًا أو USB للحفظ. يقترح البرنامج واحدًا تلقائيًا.
5. اضغط **Start Backup**، فيُنشأ مجلد اسمه `PCMigrate_YYYYMMDD_HHMM`.

### 2) على الحاسوب الجديد: Restore
1. سجّل الدخول بحساب المستخدم الجديد، وشغّل `PCMigrate.exe` من الـ USB.
2. افتح تبويب **2. Restore**. يُعثر على حزمة النقل تلقائيًا، أو اضغط Browse ثم Load.
3. اختر المستخدم من الحزمة، والملف الشخصي الذي ستستعيد إليه (افتراضيًا: أنت).
4. اضغط **Start Restore**.
5. في القائمة السفلية، حدّد البرامج واضغط **Install / transfer checked**:
   - البرامج المكتوب أمامها **Copy from package** تُنقل من الحزمة مع كل بياناتها، ولا تحتاج إنترنت (وتعمل حتى من Hiren's).
   - البرامج المكتوب أمامها **winget** تُنزَّل وتُثبَّت بصمت (تحتاج إنترنت).
   - إذا فعّلت **Prefer winget (clean install + data)**: البرنامج الذي له معرّف winget يُثبَّت نظيفًا أولًا، ثم تُسترجَع بياناته وإعداداته من الحزمة. هذا الخيار هو الأكثر أمانًا.
6. **أعد تشغيل الجهاز** (ضروري إذا نُقلت برامج فيها خدمات Services).

## محتوى حزمة النقل
```
PCMigrate_20261118_1430\
 ├─ manifest.ini
 ├─ programs.txt          ← قائمة البرامج (يمكن فتحها بـ Notepad)
 ├─ backup.log / restore.log
 ├─ System\WiFi\*.xml
 └─ Users\<user>\
      ├─ Files\Desktop, Documents, ...
      ├─ Browsers\Chrome, Edge, Firefox, ...
      └─ Settings\*.reg, wallpaper.jpg, wallpaper.ini
 └─ Apps\<program>\          ← البرامج المنقولة مع بياناتها
      ├─ app.ini            (الاسم، الإصدار، مكان التثبيت، عدد الخدمات)
      ├─ Files\             (مجلد البرنامج من Program Files)
      ├─ ProgramData\
      ├─ StartMenu\         (الاختصارات)
      ├─ Reg\               (مفاتيح HKLM + Uninstall + App Paths + svc_*.reg للخدمات)
      └─ Users\<user>\Roaming, Local, LocalLow, StartMenu, Reg (HKCU)
```

## حدود يجب معرفتها

- **كلمات المرور وملفات الكوكيز في Chrome و Edge و Brave و Opera** مشفّرة بمفتاح خاص بالجهاز (DPAPI)، فلا تنتقل. استعمل المزامنة (Sync) أو صدّرها إلى CSV. أما **Firefox** فينتقل بالكامل.
- **كلمات مرور Wi-Fi:** تُنقل كاملة إذا أُخذت النسخة من ويندوز وهو يعمل. أما من WinPE فهي مشفّرة، فتُنقل أسماء الشبكات فقط ويُطلب منك إدخال كلمة المرور.
- **نقل البرامج مباشرة ميزة تجريبية:**
  - **ينجح غالبًا مع:** البرامج المكتبية العادية، مثل Notepad++ و 7-Zip و VLC و FileZilla و Discord وبرامج المحاسبة والتسيير الصغيرة والأدوات المحمولة.
  - **ينجح جزئيًا أو يحتاج إعادة تثبيت:**
    - برامج الحماية و VPN، والبرامج التي تثبّت **تعريفات (Drivers)**. البرنامج ينبّهك عنها في السجل.
    - البرامج التي يرتبط ترخيصها بالجهاز (Office و Adobe وغيرها).
    - البرامج التي تعتمد على مكتبات مشتركة مثل Visual C++ و .NET. ثبّت هذه المكتبات على الجهاز الجديد إن لم تكن موجودة.
  - **برامج MSI** قد لا تُلغى إزالتها بشكل نظيف من "التطبيقات"، لأن قاعدة بيانات Windows Installer لا تُنقل. والحل: أعد تثبيت البرنامج فوق نفسه.
  - **ارتباطات أنواع الملفات** (Open with) لا تُنقل. اضبطها من الإعدادات.
  - **بيانات البرنامج يُبحث عنها تلقائيًا** في AppData و ProgramData والـ Registry باسم البرنامج واسم مجلده واسم ناشره. إن احتفظ برنامج ببياناته باسم مختلف، فاستعمل خيار **Prefer winget** أو انقل بياناته يدويًا.
- **البرامج المنقولة عبر winget** يجب إعادة إدخال مفاتيح تفعيلها.
- **ملفات OneDrive غير المحمّلة محليًا** (Cloud-only) تُتجاوز، لأنها موجودة في السحابة أصلًا.
- **أقراص BitLocker** يجب فتحها أولًا. وقبل الإقلاع إلى Hiren's أطفئ الجهاز إطفاءً كاملًا (Shift + Shut down) لتجنّب مشاكل Fast Startup.
- **صيغة قرص الحفظ:** استعمل NTFS أو exFAT. صيغة FAT32 لا تقبل ملفات أكبر من 4 GB، والبرنامج ينبّهك إلى ذلك.
- **الملفات المتعارضة عند الاستعادة:** إذا كان الملف موجودًا على الجهاز الجديد وهو أحدث، يُحتفظ به. وملفات المتصفح الموجودة تُعاد تسميتها إلى `.bak_...` ولا تُحذف.

## إعادة البناء (Build)

**على Linux:**
```sh
sudo apt install g++-mingw-w64-x86-64
./build.sh
```

**على Windows** (MSYS2 / MinGW-w64):
```bat
build.bat
```

ملفات المصدر:
- `src\main.cpp`: كل الكود (حوالي 2150 سطرًا)
- `src\app.rc`، `src\app.manifest`، `src\app.ico`

لإضافة برنامج إلى قائمة winget، عدّل الجدول `kWinget` في `main.cpp`.
